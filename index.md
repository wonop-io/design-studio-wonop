# Design Studio

One native project per window, from brand directions to reviewed working components.

- `main.ts` configures the shared Design Bench workflow owner; `main.js` is its self-contained generated classic entry.
- `manifest.json` declares the native agent surface and minimal permissions.
- `ui/` owns the approved app shell, comparison and isolated rendered captures.
- [Usage and agent recipe](docs/usage.md).
- [Exact native contract](docs/interface-contract.md).
- `main.test.ts` exercises the real entry with native in-memory boundary adapters.
